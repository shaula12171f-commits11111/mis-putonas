## Qué se eliminó

- Todo el sistema de chatbot / bots (Quintillizas)
- Coreano, Portugués y Ruso
- SistemaHoraDelDia, locaciones, eventos_aleatorios, QuintiImagenes

## Cómo usar

1. Clona el repo
2. Abre `index.html` o usa un servidor local:
   ```bash
   python -m http.server 8000
   ```
